## 🚀 Descripción del Proyecto

"Simon Dice" es una implementación interactiva del popular juego de memoria que desafía la capacidad del usuario para recordar y repetir secuencias de colores y sonidos. Este proyecto demuestra la construcción de un juego completamente funcional utilizando únicamente HTML, CSS y JavaScript, enfocándose en la lógica de juego, la interactividad y la experiencia del usuario.

---

## ✨ Características Principales

*   **Mecánica de Juego Clásica:** El juego genera una secuencia de colores que el jugador debe repetir.
*   **Dificultad Progresiva:** La secuencia se alarga con cada ronda exitosa, aumentando el desafío.
*   **Feedback Visual:** Los botones de color se iluminan para indicar la secuencia.
*   **Control de Juego:** Detecta si el jugador comete un error y termina la partida.
*   **Contador de Rondas:** Lleva un registro del nivel actual del jugador.
*   **Interfaz Intuitiva:** Diseño limpio y funcional que permite una fácil interacción.
*   **Diseño Responsivo:** Adaptado para ser jugado cómodamente tanto en dispositivos móviles como en escritorio.

---

## 💻 Tecnologías Utilizadas

*   **HTML5:** Estructura semántica de la página del juego y los botones.
*   **CSS3:** Estilización de los elementos visuales, efectos de iluminación para indicar la secuencia y diseño responsivo utilizando Bootstrap.
*   **JavaScript (Vanilla JS / ES6+):** Lógica del juego, generación aleatoria de secuencias, gestión del estado del juego (ronda actual, secuencia, entrada del jugador), manejo de eventos de clic y control de temporizadores (`setTimeout`, `setInterval`) para la animación de la secuencia.

## 🛠️ Cómo Iniciar el Proyecto Localmente

Este proyecto es una aplicación web sencilla y no requiere dependencias de Node.js ni herramientas de compilación. Puedes ejecutarlo directamente en tu navegador.

1.  **Clona el repositorio:**
    ```bash
    git clone https://github.com/Marcos8i22o/simon-dice.git
    ```
2.  **Navega al directorio del proyecto:**
    ```bash
    cd simon-dice
    ```
3. **Instala dependencias:**
    ```bash
    npm install
    ``` 
4.  **Abre `index.html`:**
    Simplemente abre el archivo `index.html` en tu navegador web preferido (haciendo doble clic o arrastrándolo a la ventana del navegador).

## 🧠 Lo que Aprendí / Desafíos Superados

Durante el desarrollo del juego "Simon Dice", profundicé mis conocimientos y habilidades en:

*   **Gestión de Estado de Juego:** Cómo mantener y actualizar el estado de la aplicación (secuencia, turno del jugador, puntuación) de forma efectiva en JavaScript puro.
*   **Programación Asíncrona y Temporizadores:** Uso de `setTimeout` y `setInterval` para controlar el ritmo del juego, las animaciones de la secuencia y la interacción con el usuario.
*   **Lógica de Secuencias y Comparación:** Implementación de algoritmos para generar secuencias aleatorias y comparar la entrada del usuario con la secuencia correcta.
*   **Manejo de Eventos:** Respuesta a los clics del usuario en los botones de color y gestión de la interactividad del juego.
*   **Manipulación Dinámica del DOM:** Cambiar estilos de elementos HTML (como el brillo de los botones) en respuesta a eventos del juego.
*   **Diseño de Interfaz de Usuario Interactiva:** Creación de una experiencia de usuario fluida y reactiva.
